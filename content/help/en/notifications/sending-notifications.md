Most notifications are **automatic** — they're emitted by the system when bookings change state, when an event is published, when a maintenance task is assigned, and so on.

## Where members see them

- The **Notifications** page in the sidebar (with an unread counter).
- Push notifications when the user has installed the PWA and granted permission.

## Marking read

Members can mark individual notifications read by clicking them, or **Mark all read**. Admins do not get a privileged view — every user only ever sees their own notifications.

## Common patterns

- **Booking approved / rejected** — the booking owner is notified.
- **Waitlist promoted** — the next member in line is notified when a slot frees up.
- **Event published** — interested members are notified based on their preferences.
