# Plan: #i18n — Multiple Language Support

**Status as of 2026-05-08:** Complete. 92/101 TSX files wired, 14 namespaces,
full EN + CY (machine-generated) coverage. Merged to main. Remaining follow-ups
if needed: professional Welsh translation, Phase 5 (public-page locale
resolution without JWT), Phase 6 (QA/polish).

## TL;DR

Add `next-intl` for tenant-locale-driven translations across dashboard + public
club pages. No URL locale prefix — language follows the club's configured
`Tenant.locale`. Welsh (cy) ships as the first non-English locale. ~1–2k
strings to extract.

## Phase 2: String Extraction — Dashboard (parallel with Phase 3)

Systematic extraction of hardcoded English strings into JSON message namespaces.
Replace inline text with `useTranslations('namespace')` calls in client
components and `getTranslations('namespace')` in server components.

Namespaces (one JSON file per namespace per locale):
- `common` — nav, buttons, status labels, generic
- `bookings` — availability grid, booking details, statuses, admin actions
- `notifications` — notification page, mark-read, empty state
- `maintenance` — task management, categories, priorities
- `streaming` — stream lifecycle, viewer page, token management
- `messaging` — channels, chat UI, rate-limit error
- `events` — event listing, event cards
- `admin` — platform admin pages, impersonation banner
- `onboarding` — onboarding flow steps
- `settings` — settings pages, feature toggles
- `help` — help centre chrome (not article content — already localised)
- `auth` — login, register, password reset pages

**Approach:**
- Work namespace-by-namespace (one PR per namespace or grouped by feature)
- Semantic keys: `bookings.grid.noSlots` not `bookings.text1`
- Plurals via ICU: `{count, plural, one {# booking} other {# bookings}}`
- Interpolation: `{name}` syntax

## Decisions

- **No URL locale prefix** — locale is tenant property, not user/URL concern
- **`next-intl`** — mature App Router support, ICU messages, server components
- **Welsh first** — most relevant for UK bowling club geography
- **Namespace-per-feature** — manageable files, incremental delivery
- **Currency stays GBP** — language ≠ currency; deferred to `#billing-stripe`
- **Machine translations for dev** — professional translator before production

---

## Further Considerations

1. **User-level override** — defer; add `User.localeOverride` later if demand
2. **Outbound messages** — separate `#i18n-outbound` tag once UI i18n proven
3. **RTL** — not needed for planned locales (en/cy/fr/gd all LTR)
4. **CJK / Asian locales** — one-time CSS hardening (word-break, font stack)
   when first Asian locale requested; adding the locale itself is pure content
5. **Adding new locales** — create JSON files + add to config; zero engineering
